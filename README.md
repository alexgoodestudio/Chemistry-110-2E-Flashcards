# CHM-110 Flashcards

Interactive flashcard and quiz app for **CHM-110 (College Chemistry I)**, built as a
personal study tool by [Alex Goode](https://github.com/alexgoodestudio). Questions are
sourced from the [OpenStax Chemistry 2e](https://openstax.org/details/books/chemistry-2e)
textbook and from actual course quizzes, with a "why" explanation written for every card.

## About this study guide

A free study guide for **CHM-110 (College Chemistry I) at Midlands Technical College**,
made by a student for the 2026 class and shared for classmates and anyone else taking
general chemistry. It follows the course chapter by chapter:

- **Chapter 1 & 2 tabs**: OpenStax textbook review questions and real course quiz
  questions (measurement, atoms, ions, the periodic table).
- **Ch 4 Study Guide tab**: stoichiometry review built from the instructor's practice
  sheet. It covers how to recognize each problem type (molarity, dilution, titration,
  mass-to-mass, limiting reactant, percent yield), key formulas, balancing, predicting
  reactions, net ionic equations, empirical/molecular formulas, and worked Practice 1-9
  problems. Cards are flip-and-self-grade ("Got it" / "Missed it").

It is a living document, so new cards get added as the semester goes on. Your progress
is saved in your own browser only. This is a student-made study aid, not an official
Midlands Technical College resource. Check answers against your textbook and instructor.

**Use it here:** https://alexgoodestudio.github.io/Chemistry-110-2E-Flashcards/


## Running locally

Open `index.html` directly in a browser, or serve the folder:

```sh
python3 -m http.server 8000
# then visit http://localhost:8000/
```
