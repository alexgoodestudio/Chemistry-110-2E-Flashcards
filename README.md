# CHM-110 Flashcards

Interactive flashcard and quiz app for **CHM-110 (College Chemistry I)**, built as a
personal study tool by [Alex Goode](https://github.com/alexgoodestudio). Questions are
sourced from the [OpenStax Chemistry 2e](https://openstax.org/details/books/chemistry-2e)
textbook and from actual course quizzes, with a "why" explanation written for every card.

**Use it here:** https://alexgoodestudio.github.io/Chemistry-110-2E-Flashcards/


## Running locally

Open `index.html` directly in a browser, or serve the folder:

```sh
python3 -m http.server 8000
# then visit http://localhost:8000/
```
